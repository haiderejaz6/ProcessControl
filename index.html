About this course

PSE-823 bridges basic single-loop process control and Model Predictive Control (MPC), with an emphasis on the economic aspects of advanced control technologies. Lectures are authored as Jupyter notebooks — combining explanatory text with live Python (numpy, scipy, sympy, python-control, GEKKO) — and exported to self-contained reveal.js slide decks. The syllabus, objectives and reading list are on the course info page.

  • Slides

    The lecture as delivered in class. Opens in any browser and runs fully offline — no server or internet connection needed.

  • Colab

    The same lecture as a runnable notebook in the cloud. Nothing to install; edit the code and re-run any example yourself.

  • Binder

    Runs the notebook live on a clean copy of this repo. Click the slideshow button (or press Alt+R) to present it as slides.

  • Notebook

    The raw .ipynb for local use in Jupyter, with every figure and code cell included.
