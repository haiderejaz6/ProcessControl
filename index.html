About this course

PSE-823 bridges basic single-loop process control and Model Predictive Control (MPC), with an emphasis on the economic aspects of advanced control technologies. Lectures are authored as Jupyter notebooks — combining explanatory text with live Python (numpy, scipy, sympy, python-control, GEKKO) — and exported to self-contained reveal.js slide decks that work fully offline.
