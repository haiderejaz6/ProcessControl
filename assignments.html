Join the Teams class

How to submit

  • Derivations must be done by hand. Submit clear photos or scans of your handwritten working as one PDF. Typed derivations are not accepted.
  • Code goes in the starter notebook. Submit it as the .ipynb file or as a PDF export of it. Run Restart and run all first so every output is visible.
  • Where: the Assignments tab of the PSE-823 class on Microsoft Teams. If you are not in the class yet, open the team link and request to join.
  • Your values: each assignment uses d = the last digit of your Reg #, which sets your numbers. Discuss freely, but your derivations, code and answers must be your own.
